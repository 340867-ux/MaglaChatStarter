# MAGLA Chat Starter — privacy

The extension is local-first.

- It stores only the phrase, plugin/tool list, and message template in the browser's local extension storage.
- It inserts the rendered template into the currently visible chat composer after an explicit user click.
- It never sends the message automatically.
- It does not read, store, or transmit conversation history.
- It makes no network requests and contains no analytics or remote code.
- Site access is limited to ChatGPT, Claude, and Gemini chat pages so the insert button can work there.
